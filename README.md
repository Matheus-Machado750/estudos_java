# Estudos em Java ☕

Este repositório reúne **exercícios de lógica de programação e prática em Java**, com foco nos fundamentos da linguagem e nos conceitos iniciais de Programação Orientada a Objetos (POO). O objetivo é praticar a linguagem, desenvolver o raciocínio lógico e aplicar os conhecimentos por meio de pequenos desafios e exercícios.

---

## Objetivo

- Praticar os fundamentos da linguagem Java.
- Aprofundar os conhecimentos em Programação Orientada a Objetos (POO).
- Desenvolver o raciocínio lógico e a capacidade de resolver problemas.
- Manter os exercícios organizados e acompanhar a evolução dos estudos.

---

## Conteúdos Estudados

- Fundamentos da linguagem Java.
- Classes e objetos.
- Construtores.
- Enums.
- Sobrecarga de métodos (*method overloading*).
- Métodos, parâmetros e assinaturas.
- Conceitos iniciais de Programação Orientada a Objetos (POO).

> *Obs.: novos conceitos e exercícios serão adicionados conforme o avanço dos estudos.*
